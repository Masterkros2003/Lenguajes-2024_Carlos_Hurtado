Conversión y Adaptación de Documentos XML

Resumen sobre el uso de XML, XPath, y formatos de intercambio de datos

Objetivo General

Comprender los lenguajes de transformación de documentos XML, navegar árboles XML mediante XPath, y utilizar herramientas relacionadas.

Lenguajes de Transformación XML

XML (Extensible Markup Language): Un formato jerárquico y extensible, ideal para documentos complejos y para la integración de sistemas.

XSL (eXtended Stylesheet Language): Extensión de CSS enfocada en XML. Incluye componentes como XPath, XSLT y XSL-FO.

XPath

Lenguaje para navegar y seleccionar nodos en documentos XML.

  • Acceso a nodos específicos, extracción de datos y cálculos.
  • Funciones destacadas: contains(), starts-with(), text(), last(), count().

Formatos de Intercambio de Datos

JSON (JavaScript Object Notation): Formato ligero y eficiente, basado en pares clave-valor. Ideal para APIs REST y configuraciones de aplicaciones.

CSV (Comma-Separated Values): Formato tabular y simple, adecuado para datos en hojas de cálculo y procesos simples.

YAML (YAML Ain't Markup Language): Formato legible y compacto, popular en configuraciones de sistemas y despliegue de infraestructura.
