Resumen XML

¿Qué es XML?

Es un lenguaje de marcado de propósito general definido por el W3C

El propósito principal del lenguaje es compartir datos a través de diferentes sistemas, como Internet.

  • No es un sustituto de HTML.
  • No es un gestor de bases de datos.
  • No es un estándar de comunicación ni un lenguaje de programación.

Características de XML

  • Lenguaje de estructura libre: las etiquetas no están predefinidas.
  • Documentos validados y bien formados.
  • Sigue reglas estrictas de sintaxis, como el cierre obligatorio de etiquetas.
  • Usa espacios de nombres para evitar ambigüedades.
  • Consta de dos partes principales: el prólogo y el cuerpo.
  • Debe cumplir las reglas W3C para estar bien formado.
  • Utiliza esquemas en forma de árbol con una única raíz.
  • Los documentos se validan para asegurar su estructura correcta.

Validación XML

Permite comprobar si un documento se ajusta a una serie de reglas predefinidas

  • DTD: Definición de Tipo de Documento para describir la estructura.
  • XML Schema: Un lenguaje basado en XML que mejora el DTD.
  • Un DTD describe la estructura del documentos
      • Elementos
      Orden
  • Ubicación de DTD
      • Interno. En el propio documento
      Externo, referenciado por URL
      Mixto

Tipos de elementos DTD

Elemento

  • Cardinalidad Número de veces que aparece el elemento descendiente
      • ?: El elemento aparece 0 o 1 vez.
      *: Número de veces que aparece el elemento descendiente
      +: Número de veces que aparece el elemento descendiente
  • Secuencia Se indican los elementos que deben de aparecer en el fichero XML.

    • X, Y: Indica que el elemento X tiene que aparecer a continuación de Y. (X|Y): Indica que aparece el elemento X o el elemento Y, pero no los dos al mismo tiempo.

  • Combinación Se pueden combinar los símbolos de secuencia y los de cardinalidad.

    Tipos

    Propiedad Significado
    CDATA Cadena de texto. Valor alfanumérico.
    Enumeraciones Permite indicar varios valores.
    ENTITY Entidad definida previamente.
    ENTITIES Conjunto de entidades.
    IDREF Referencia al identificador de otro elemento.
    IDREFS Referencia a un conjunto de identificadores.
    ID Identificador único para identificar elementos.
    NOTATION Se indican datos que no son XML.
    NMTOKEN Un nombre sin espacios en blanco.
    NMTOKENS Lista de nombres.

    Valores

    Propiedad Significado
    #REQUIRED El atributo es obligatorio.
    #IMPLIED El atributo es opcional.
    #FIXED valor El atributo es obligatorio y se le asigna un valor por defecto que es el único valor que puede tener.
