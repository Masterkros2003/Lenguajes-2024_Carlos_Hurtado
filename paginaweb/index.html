Descripción de la Asignatura: Lenguajes de Marcas

La asignatura de Lenguajes de Marcas está orientada al estudio y uso de sistemas de etiquetado que permiten estructurar, representar y transferir datos en diferentes formatos. Este conocimiento es esencial en áreas como el desarrollo web, la interoperabilidad de sistemas y la gestión de información. Los lenguajes de marcas se utilizan ampliamente en la creación de sitios web, aplicaciones y servicios que requieren organización y estandarización de datos.

Contenidos Principales:

  • Fundamentos de los Lenguajes de Marcas:
    • Definición y características.
    • Diferencias entre lenguajes de marcas y lenguajes de programación.
    • Estándares y aplicaciones comunes.
  • HTML (HyperText Markup Language):
    • Estructura básica de un documento HTML.
    • Elementos y atributos principales.
    • Integración de contenido multimedia (imágenes, videos, audios).
  • CSS (Cascading Style Sheets):
    • Uso de CSS para el diseño y personalización de documentos.
    • Selectores, propiedades y estilos avanzados.
  • XML (eXtensible Markup Language):
    • Introducción y objetivos.
    • Creación de documentos XML bien formados.
    • Validación mediante DTD (Document Type Definition) y XML Schema.
  • Lenguajes de Marcas en la Web:
    • Interacción entre HTML, CSS y JavaScript.
    • Aplicaciones modernas: JSON, Markdown y otros formatos basados en marcas.
  • Aplicaciones Prácticas:
    • Creación de páginas web estáticas.
    • Uso de XML para la transferencia de datos entre sistemas.
    • Integración de lenguajes de marcas con tecnologías actuales.
